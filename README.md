# Amazon-Bookla-sales-Analysis
Analyzed 500+ Amazon book listings using Python to study pricing, ratings, popularity, and format-wise trends. Performed web scraping, data cleaning, exploratory data analysis, and hypothesis testing to extract actionable business insights for pricing and customer behavior.


### Problem Understanding
Defined the business problem to analyze how book prices, ratings, popularity, and formats influence customer behavior on Amazon.

### Data Collection (Web Scraping)
Collected book data from Amazon using Python and Selenium, scraping multiple pages to gather 500+ book listings.

### Raw Dataset Creation
Stored scraped data in raw format containing inconsistencies such as missing values, currency symbols, and mixed data types.

### Data Cleaning & Preprocessing
Removed currency symbols and converted prices to numeric values
Standardized rating counts and handled missing values
Converted release dates into a consistent format
Removed duplicates and invalid records

### Feature Engineering
Created new analytical columns such as:
Price Category
Rating Category
Popularity Category
Book Age
Value for Money

### Exploratory Data Analysis (EDA)
Performed:
Univariate analysis to study individual features
Bivariate analysis to analyze relationships between variables
Multivariate analysis to understand combined effects

### Data Visualization
Built meaningful visualizations using Matplotlib and Seaborn to highlight trends and patterns.

### Hypothesis Testing
Applied statistical tests (ANOVA, Chi-square) to validate whether observed differences were statistically significant.

### Insights & Interpretation
Interpreted results in both technical and business-friendly terms to extract actionable insights.

### Conclusion & Business Recommendations
Summarized findings and provided recommendations for pricing strategy, format selection, and customer decision support.
